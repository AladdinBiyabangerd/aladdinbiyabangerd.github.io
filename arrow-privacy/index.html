Emal edilən məlumatlar

Oyun irəliləyişi, coinlər, ayarlar və yaş qrupu cihazda saxlanılır. Daxil olduqda Firebase Authentication email, istifadəçi ID-si və giriş provayderi məlumatlarını emal edir. Bulud sinxronizasiyası oyun irəliləyişi və profili saxlayır. Reytinq və çağırışlar oyunçu ID-si, nickname, xal və nəticələri emal edir. Şikayət, bloklama və dəstək sorğuları həmin funksiyalardan istifadə etdikdə emal olunur. Ödənişləri Google Play emal edir; tətbiq kart məlumatını deyil, alış tokenlərini və alış hüquqlarını istifadə edir.

Ölkə/region kodu və həftəlik hədiyyə

Ölkə/region reytinqləri üçün tətbiq SIM kartdan, mobil şəbəkədən və ya telefonun region ayarından iki hərfli ölkə/region kodunu (məsələn, AZ) oxuyur. Bu kod dəqiq məkan deyil və hazırda harada olduğunu göstərmir; tətbiq bunun üçün GPS və ya məkan icazəsi istifadə etmir. Hesaba daxil olub nickname seçmisənsə, kod profilində və reytinq qeydlərində saxlanılır və reytinqlərdə nickname-in yanında bayraq kimi digər oyunçulara göstərilir. Həftəni dünyada 1-ci yerdə bitirsən, həftəlik hədiyyənin yalnız bir dəfə verilməsi üçün oyunçu ID-n, ulduz sayın və həftə ilə qeyd saxlanılır; bu qeyddə nickname və ölkə/region kodu yoxdur. Hesabı silərkən profil və reytinq qeydlərin, o cümlədən bu kod, silinir.

Reklam və diaqnostika

Google AdMob reklam/cihaz identifikatorları, reklamla qarşılıqlı əlaqə, cihaz məlumatları və IP-dən təxmini məkanı reklam göstərmək, ölçmək və sui-istifadənin qarşısını almaq üçün emal edir. Razılıq və yaş qaydaları emala təsir edir. Firebase Analytics və Crashlytics məxfilik seçimlərinə və tətbiqin konfiqurasiyasına uyğun istifadə hadisələri, identifikatorlar, cihaz və çökmə məlumatlarını emal edir. Remote Config tətbiq ayarlarını çatdırır. Unity Ads AdMob mediation vasitəsilə reklam partnyorudur; cihaz identifikatorları, texniki məlumatlar və reklamla qarşılıqlı əlaqəni emal edə bilər. Razılıq siqnalları mediation inteqrasiyası ilə ötürülür. Diaqnostika məlumatlarını tam anonim hesab etmirik.

Məqsəd və xidmət təminatçıları

Məlumatlar oyunun işi, sinxronizasiya, sosial funksiyalar, alışlar, reklamlar, sui-istifadənin qarşısının alınması və xətaların araşdırılması üçün istifadə olunur. Google xidmətlərinin öz şərtləri var və məlumatları ölkəndən kənarda emal edə bilərlər. Sayt GitHub Pages-də yerləşir; GitHub texniki sorğu məlumatlarını emal edə bilər. Hesab məlumatlarını satmırıq.

Seçimlər və uşaqlar

Reklam/məxfilik seçimlərini Ayarlar → Gizlilik bölməsində dəyiş. Hesaba giriş məcburi deyil. 13 yaşdan kiçiklər qonaq rejimindən istifadə edir; hesab, bulud və sosial funksiyalar məhdudlaşdırılır. 13 yaşdan kiçik və yaşı məlum olmayan oyunçular üçün tətbiq reklam sorğusu göndərmir və reklam göstərmir. 13–15 yaş qrupu üçün reklam sorğuları fərdiləşdirilmir və yaş razılığı məhdudiyyəti tətbiq olunur. Unity Ads üçün fərdiləşdirməyə razılıq verilməyən kontekstual reklam ayarları istifadə olunur. Məlumatlara çıxış, düzəliş və silmə üçün bizə yaz.

Saxlanma və silmə

Lokal məlumatlar sıfırlama və ya tətbiq məlumatlarının silinməsinədək qalır; Android ehtiyat nüsxələrinin ayrıca saxlanma qaydası ola bilər. Обрабатываемые данные

Прогресс, монеты, настройки и возрастная группа хранятся на устройстве. При входе Firebase Authentication обрабатывает email, ID пользователя и данные провайдера входа. Облачная синхронизация хранит прогресс и профиль. Рейтинги и испытания используют ID игроков, псевдонимы, очки и результаты. Жалобы, блокировки и обращения обрабатываются при использовании этих функций. Платежи обрабатывает Google Play; приложение использует токены покупок и сведения о правах, а не данные банковской карты.

Код страны/региона и еженедельная награда

Для рейтингов по странам/регионам приложение считывает двухбуквенный код страны/региона (например, AZ) из SIM-карты, мобильной сети или настройки региона телефона. Этот код не является вашим точным местоположением и не показывает, где вы находитесь сейчас; приложение не использует для него GPS или разрешение на доступ к местоположению. Если вы вошли в аккаунт и выбрали псевдоним, код хранится в вашем профиле и в записях рейтинга и показывается другим игрокам в виде флага рядом с псевдонимом. Если вы завершили неделю на 1-м месте в мире, сохраняется запись с вашим ID игрока, количеством звёзд и неделей, чтобы еженедельную награду можно было получить только один раз; в ней нет псевдонима и кода страны/региона. Профиль и записи рейтинга, включая код, удаляются при удалении аккаунта.

Реклама и диагностика

Google AdMob обрабатывает рекламные/устройственные идентификаторы, взаимодействия с рекламой, сведения об устройстве и приблизительное местоположение по IP для показа, измерения и защиты рекламы. На обработку влияют согласие и возрастные ограничения. Firebase Analytics и Crashlytics обрабатывают события, идентификаторы, сведения о приложении/устройстве и сбоях с учётом настроек конфиденциальности и конфигурации приложения. Remote Config передаёт настройки. Unity Ads — рекламный партнёр через AdMob mediation; он может обрабатывать идентификаторы устройств, технические данные и взаимодействия с рекламой. Сигналы согласия передаются через mediation. Диагностические данные не считаются полностью анонимными.

Цели и поставщики услуг

Данные нужны для работы игры, синхронизации, социальных функций, покупок, рекламы, предотвращения злоупотреблений и исправления ошибок. У сервисов Google есть собственные условия; обработка возможна за пределами вашей страны. Сайт размещён на GitHub Pages, который может обрабатывать технические сведения о запросах. Мы не продаём данные аккаунта.
